## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** and **Sentiment Analysis** on skincare product reviews. The goal is to extract meaningful insights from customer feedback to understand product sentiment, identify trends, and support data-driven business decisions in the beauty/skincare industry.

## 🎯 Objectives

- Perform comprehensive EDA on skincare product dataset
- - Apply NLP techniques to analyze customer sentiment
  - - Visualize sentiment distribution and product performance
    - - Identify top-rated and bottom-rated products based on reviews
     
      - ## 🛠️ Technologies Used
     
      - | Tool/Library | Purpose |
      - |---|---|
      - | **Python** | Primary programming language |
      - | **Jupyter Notebook** | Interactive analysis environment |
      - | **Pandas** | Data manipulation and analysis |
      - | **Matplotlib / Seaborn** | Data visualization |
      - | **NLTK / TextBlob** | Natural Language Processing |
      - | **WordCloud** | Visual representation of text data |
      - | **Scikit-learn** | Machine learning preprocessing |
     
      - ## 📊 Dataset
     
      - - **Domain:** Skincare/Beauty products
        - - **Data:** Product names, descriptions, ratings, customer reviews
          - - **Volume:** Multiple product categories and thousands of reviews
           
            - ## 🔬 Methodology
           
            - 1. **Data Collection & Cleaning** — Handle missing values, remove duplicates, normalize text
              2. 2. **Exploratory Data Analysis** — Distribution of ratings, product categories, price ranges
                 3. 3. **Text Preprocessing** — Tokenization, stopword removal, stemming/lemmatization
                    4. 4. **Sentiment Analysis** — Classify reviews as Positive, Negative, or Neutral
                       5. 5. **Visualization** — Word clouds, sentiment distribution charts, correlation plots
                          6. 6. **Insights** — Extract actionable insights from results
                            
                             7. ## 📈 Key Findings
                            
                             8. - Majority of reviews were positive, reflecting customer satisfaction
                                - - Certain ingredient-specific products received higher sentiment scores
                                  - - Price range and brand reputation correlated with review sentiment
